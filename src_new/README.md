# NeoDAX Static Mach-O Analysis Framework

## 概要

これは、Mach-O ファイルの静的解析を専門的に行うフレームワークです。特に将棋AIのようなアプリケーション向けに、実行フローとデータ依存性の追跡に焦点を当てています。

## 特徴

### 1. Mach-O 静的解析
- Mach-O ファイル形式（FAT、32-bit、64-bit）の完全サポート
- セクション、シンボル、関数の解析
- エントリーポイントと呼び出し関係の検出

### 2. 依存性追跡システム (Dependency Flow Analysis)
- 変数と関数間の依存性グラフの構築
- データフローとコントロールフローの追跡
- 変数使用状況の追跡
- 依存性パスの発見

### 3. 実行順序予測モジュール
- 関数・ブロック・命令レベルの実行順序予測
- 位相ソートによる順序決定
- 並列実行可能性の検出
- クリティカルパス解析

### 4. 並列実行検出モジュール
- 並列実行パターンの検出
- ビームサーチなどの並列探索アルゴリズムの特定
- ディスパッチポイントと同期ポイントの特定
- スレッドプール、タスク並列、パイプライン並列の検出

### 5. 状態追跡・回帰分析モジュール
- 状態変化のチェックポイント管理
- 変数のライフタイム追跡
- 状態の回帰パターン検出
- 将棋AI向けの盤面状態、局面、評価値の追跡

## 将棋AI向け特殊機能

### 盤面状態追跡
- 盤面（board）状態の変化追跡
- 局面（position）の遷移分析
- 状態のハッシュ値による比較

### 着手履歴追跡
- 着手（move）の生成と実行の追跡
- 着手履歴の構築
- 合法手生成の分析

### 探索木状態追跡
- 探索ノードの状態変化追跡
- 探索木の構築と遍歴の分析
- 探索深さと幅の追跡

### 評価値追跡
- 評価関数の状態変化追跡
- 評価値の計算と更新の分析
- 最善手選択の追跡

## ビームサーチ分析

### 並列ビームサーチ検出
- ビームサーチディスパッチ関数の特定
- 並列実行パターンの検出
- ビーム幅と探索深さの推定

### 引数追跡
- ビームサーチ関数への引数追跡
- 状態、着手、深さなどの引数特定
- 戻り値の追跡

### 実行順序分析
- ビームサーチ内の実行順序予測
- 並列実行の同期ポイント特定
- メッセージ受信後の実行条件保持

## 使用方法

### 基本的な使い方

```bash
# すべての解析を実行
neodax_static -a binary

# 依存性解析のみ
neodax_static -d binary

# 実行順序解析
neodax_static -e binary

# 並列実行検出
neodax_static -p binary

# 状態追跡
neodax_static -t binary
```

### 将棋AI向け解析

```bash
# 将棋AI特有の解析をすべて実行
neodax_static --shogi shogi_engine

# 盤面状態追跡
neodax_static --track-board shogi_engine

# 着手履歴追跡
neodax_static --track-moves shogi_engine

# 探索木状態追跡
neodax_static --track-search shogi_engine

# 評価状態追跡
neodax_static --track-eval shogi_engine

# ビームサーチ分析
neodax_static -p --beam-search shogi_engine
```

### 依存性解析の詳細設定

```bash
# 特定の関数をターゲット
neodax_static -d --depflow-func search_function binary

# 特定の変数を追跡
neodax_static -d --depflow-var board_state binary

# 依存性追跡の深さを設定
neodax_static -d --depflow-depth 20 binary

# 依存性グラフをDOTファイルに出力
neodax_static -d --depflow-dot dep_graph.dot binary
```

## モジュール構成

### core/
- `macho_static.h/c`: Mach-O ファイル解析のコアモジュール
- Mach-O フォーマットのパーサ
- セクション、シンボル、関数の解析

### analysis/
- `depflow.h/c`: 依存性追跡システム
- 依存性グラフの構築
- 変数使用状況の追跡
- 依存性パスの発見

### flow/
- `execution_order.h/c`: 実行順序予測モジュール
- 実行グラフの構築
- 位相ソートとスケジューリング
- クリティカルパス解析

- `parallel_detection.h/c`: 並列実行検出モジュール
- 並列実行パターンの検出
- ビームサーチ分析
- ディスパッチパターン分析

### tracking/
- `state_tracking.h/c`: 状態追跡・回帰分析モジュール
- 状態チェックポイント管理
- 状態変化の追跡
- 回帰パターンの検出

## 将来の拡張

1. **動的解析との統合**: 静的解析結果を基にした動的解析のガイド
2. **機械学習支援**: 解析結果を機械学習モデルの入力として利用
3. **ビジュアライゼーション**: 解析結果のインタラクティブなビジュアライゼーション
4. **他形式サポート**: ELF、PE 形式への拡張
5. **高度な最適化**: 解析パフォーマンスの向上
